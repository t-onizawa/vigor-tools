個人の方へ

自分の個人情報が漏れたかも、
と思ったら

利用しているサービスから「個人情報が漏れた」という連絡が来たら、漏れた情報の種類によって、最初にやることが違います。まず下の確認から始めてください。

このページは、メールアドレスやパスワードなどの入力を求めません。漏れたかどうかを判定するものでもありません。チェックはこのページに保存され、送信されることはありません。

まず確認：何が漏れたと書いてありますか

会社の発表や連絡で、漏れた情報の種類を確認してください。複数あてはまる場合は、それぞれの対処が必要です。タップすると、その「まずやること」に移動します。

A

パスワード・IDが漏れた場合 → まずやること

  1. そのサービスのパスワードを、すぐ変更する変更は公式アプリ・公式サイトから。メール内のリンクからは開かないでください
  2. 同じパスワードを使っている他のサービスも、全部変更する
  3. ログイン履歴を見て、知らないログインがないか確認する他の端末のログインは解除します
B

クレジットカード情報が漏れた場合 → まずやること

  1. カード会社に連絡する不正な利用がないかの確認、利用停止や再発行の相談をします
  2. 利用明細に、身に覚えのない請求がないか確認するしばらくの間、定期的に確認してください
C

氏名・住所・電話番号・メールアドレスが漏れた場合 → まずやること

  1. パスワードの変更より先に、「便乗した詐欺への警戒」をするその情報を使った詐欺のメール・SMS・電話・郵便物が来る可能性があります
  2. 突然のメールやSMSは、基本的に詐欺だと考えて無視し、リンクや添付を開かない自分の名前が書いてあっても油断しないでください
  3. 不審な着払いの荷物は受け取らない
D

運転免許証など、本人確認書類の画像が漏れた場合 → まずやること

なりすまして、クレジットカードやローンの契約をされるおそれがあります。

  1. 信用情報機関への「本人申告」（漏れた事実の登録）を検討する不正な契約への一定の抑止になります。完全に防げる保証はありません。窓口は、日本信用情報機構（JICC）／株式会社シー・アイ・シー（CIC）／全国銀行個人信用情報センターです
  2. 身に覚えのない契約や請求の郵便物が届いていないか、しばらく注意する
？

分からない場合

  1. そのサービスの公式サイト・公式アプリの案内か、サポート窓口で確認する
  2. それでも分からない場合は、A（パスワード変更）と B（明細の確認）を先にやっておくと安心です

共通の初動

漏れた情報の種類にかかわらず、共通してやっておきたいことです。

日頃

日頃の対策

漏洩は「起きるもの」として備える、普段からの対策です。

やってはいけないこと

  • 漏洩を知らせるメール内のリンクから、パスワード変更やログインをする――本物そっくりの偽ページに誘導される典型的な手口です
  • 「あなたの情報が売られています。消すには料金が必要です」と言う業者に払う――漏洩に便乗した詐欺の可能性があります。まず公的窓口へ
  • 漏洩のお知らせ画面や個人情報のスクリーンショットをSNSに載せる――自分の情報をさらに広めることになります（保存は自分の端末の中だけに）
  • 何も確認せず「自分は関係ない」と決めつける――使っていないと思っている古いサービスから漏れることもあります

注意書き

  • このページで「自分の情報が実際に漏れたかどうか」を判定することはできません。確認は各サービスの公式案内・問い合わせ窓口で行ってください。
  • 信用情報機関への本人申告は、不正な契約への一定の抑止が期待できるものです。完全に防げるものではありません。
  • 相談窓口の電話番号・受付時間は2026年11月に公式ページで確認した情報です。変わっている場合があるため、利用時に各機関のページで再確認してください。
  • 法人・事業者の方の対応は、法人向けの初動フロー（全28項目）と予防編（全22項目）を参照してください。
