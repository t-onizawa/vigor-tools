# VIGOR MATSURI

茨城・千葉・埼玉・東京周辺の山車祭りを対象に、「山車が出るか」
「神輿が出るか」「曳き回しがあるか」「昼と夜どちらが見どころか」など、
実際に見に行く人が知りたい現地体験情報をまとめる祭りガイドです。

VIGOR LAB の姉妹プロジェクトであり、VIGOR TOOLS とは別プロダクトです。
企画の判断基準は `CONCEPT.md`、未着手項目・追加候補は `Backlog.md` を参照してください。

## 現在のステータス

企画・情報設計の段階です。サイト実装・祭り情報の登録はまだ行っていません。

## 技術構成（予定）

- HTML / CSS / JavaScript のみ
- 外部API・ログイン・保存機能なし
- GitHub Pages で静的配信

## ローカル実行方法

実装後、`matsuri/` ディレクトリ内の `index.html` をブラウザで直接開くか、
簡易サーバーで確認します。

```
cd matsuri
python3 -m http.server 8000
```

`http://localhost:8000` で確認できます（実装後に有効な手順です）。
