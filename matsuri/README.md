# VIGOR MATSURI

茨城・千葉・埼玉・東京・栃木・群馬の山車祭りを対象に、「山車が出るか」
「神輿が出るか」「曳き回しがあるか」「昼と夜どちらが見どころか」など、
実際に見に行く人が知りたい現地体験情報をまとめる祭りガイドです。

VIGOR LAB の姉妹プロジェクトであり、VIGOR TOOLS とは別プロダクトです。
企画の判断基準は `CONCEPT.md`、実務ルールは `CLAUDE.md`、
未着手項目・追加候補は `Backlog.md` を参照してください。

## 情報品質方針

掲載情報は祭り公式・自治体・観光協会などの一次情報を優先して確認し、
確認できない項目は推測で埋めず null／未確認として扱います。開催確認
ステータス（開催確認済み・開催予定・未確認・中止・延期・終了）を
祭りごとに明示します。詳細は `about.html`（サイトについて）を参照。

## 技術構成

- HTML / CSS / JavaScript のみ
- 外部API・ログイン・保存機能なし
- GitHub Pages で静的配信

## ローカル実行方法

`matsuri/` ディレクトリ内の `index.html` をブラウザで直接開くか、
簡易サーバーで確認します。

```
cd matsuri
python3 -m http.server 8000
```

`http://localhost:8000` で確認できます。
